ANGLER GEAR — WEBSITE E-COMMERCE DEMO

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder angler_gear.
3. Klik dua kali index.html atau buka melalui browser.
4. Pastikan koneksi internet tersedia untuk memuat Google Fonts.

STRUKTUR
- index.html       : struktur halaman website
- style.css        : desain, warna, layout, dan responsive
- script.js        : filter produk, pencarian, keranjang, dan demo checkout
- images/          : 3 gambar produk JPG

CATATAN
Website ini merupakan front-end demo. Checkout belum terhubung ke payment gateway,
database, atau WhatsApp. Harga dan detail produk dapat diedit langsung di index.html
dan script.js.
